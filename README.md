# TaskFlow – Smart Task Management Platform

Manage Tasks. Track Progress. Achieve More.

TaskFlow is a modern and responsive task management platform designed to help individuals, freelancers, students, and teams organize their work, manage projects, track progress, and improve productivity from one place.

This project is developed as part of the Sankar Group – Front-End Development Internship Assignment.

## ✨ Features

### Landing Page
- Modern and responsive navigation bar.
- Attractive hero section with call-to-action buttons.
- Features section highlighting platform capabilities.
- How It Works section.
- Pricing plans (Free and Pro).
- Testimonials section.
- Contact and demo request form.
- Professional footer with navigation links.

### Task Management Dashboard
- Create new tasks.
- Edit existing tasks.
- Delete tasks with confirmation.
- Set task priorities (Low, Medium, High).
- Set task deadlines.
- Manage task statuses:
  - Pending
  - In Progress
  - Completed
- Search tasks by title.
- Filter tasks by status and priority.
- Dashboard statistics and progress tracking.
- Save task data using browser LocalStorage.

### UI/UX
- Modern SaaS-inspired interface.
- Responsive design for desktop, tablet, and mobile.
- Smooth animations and transitions.
- Interactive buttons and hover effects.
- Clean typography and consistent layouts.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Navigate to the Project Folder

cd taskflow-landing-page

### 3. Install Dependencies

npm install

### 4. Start the Development Server

npm run dev

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

http://localhost:5173

- Desktop
- Laptop
- Tablet

## 💾 Data Storage

This project uses browser LocalStorage to store task information locally.

- No backend server is required.
- No external database is used.
- Task data remains available after refreshing the browser on the same device and browser.

## 🔒 Project Scope

This is a **frontend-only application**.

The following are not included:
- Backend development
- Database integration
- User authentication APIs
- Payment gateway integration
- Server-side functionality

All interactive features are implemented using React.js and browser-side functionality.

## 🎯 Project Objective

The main objective of this project is to demonstrate practical front-end development skills, including:

- Building reusable React components.
- Creating responsive user interfaces.
- Managing application state using React Hooks.
- Implementing CRUD operations.
- Working with LocalStorage.
- Creating interactive forms with validation.
- Improving user experience with animations.
- Maintaining clean and readable code.
